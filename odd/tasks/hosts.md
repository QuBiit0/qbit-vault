- L4. P1 done by gentle-ai-worker (RED: undefined writeAtomic). `internal/filemerge`, standard library only: snapshots to `backups/<ts>/<encoded absolute path>` (mirrored tree), atomic write (temp, fsync, rename, dir fsync), order- and format-preserving JSON merge/unmerge of owned keys and marker-identified array entries, a TOML text editor for `[mcp_servers.qbit-vault]` and its subtables (comments, CRLF, BOM, no trailing newline; duplicate or dotted definitions refused), receipts (`exact`, `created`) and a 3-way revert (byte restore when the file is still ours, else strip only our entries). A symlinked target file is refused (`ErrSymlink`). Markers for the adapters: `qbit-vault hook` for hook entries, the full `Read(<home>/**)` string for deny.
- L5. Parent review found that vault pruning (newest 20 directories under `backups/`) would also delete config snapshots, so uninstall could no longer restore a config byte for byte, and that `restore` would list config snapshots as empty vault backups. Both now consider only directories holding files only (`vaultBackup`); a config snapshot always mirrors a directory tree. RED observed for both (the first ListBackups test passed vacuously with an invalid backup id; fixed to a valid id and re-checked RED).
- L6. P2 done by gentle-ai-worker (RED: undefined HostState/ReadHosts/WriteHost, missing hosts/fake, undefined hostRegistry). `internal/hosts`: Adapter{Name, Detect, Steps}, Step{Apply, Revert, Check} over filemerge, registry, runner (receipts saved after each changed step; a failing step stops only its host; a no-op run writes nothing). state.json `hosts` section via `vault.ReadHosts/WriteHost` under the vault lock. `init` validates `--agents` first, creates the vault when missing, registers detected or named hosts on every run (`--agents none` skips), runs `doctor`; a vault-only run keeps the old output exactly (doctor's report prints only when a host was processed or a problem was found: documented exception to R-INS-06). `doctor` is read-only (byte comparison of home and host tree in tests), exit 0/1, checks vault (quiet open, `locked` counts as ok), permissions, every registered host step (drift warns), and sync from `state.json.remote.summary`. The registry is empty in release builds until P4/P5/P7; the fake adapter is test-only. Open: no audit record for host registration; `openSessionQuiet` can repair state.json on a legacy vault (same as `remote status`).
- L7. P3 done in two worker runs (the first attempt failed mid-run and left no files). P3a `hook pre-bash` (RED: undefined RunPreBash/Run/Event; CLI `unknown command`): shell scanner across chains, subshells, wrappers, env prefixes, paths, `.exe`, `npx`; allows only `version help list describe grants audit doctor` and `exec` (its `--` command checked recursively), denies every other qbit-vault subcommand, unknown ones and unparseable lines that mention qbit-vault; fails open with a fixed warning (`additionalContext` + `systemMessage`, no `permissionDecision`, because `allow` would skip the user's permission prompt). ~13 us in-process, ~80 ms as a process. P3b `hook post-bash`, `post-read` (redact every string of `tool_response` with every stored value >= 8 bytes plus shorter granted ones, re-emitted as `updatedToolOutput` in the same structure) and `hook user-prompt` (blocks a prompt holding a stored value or a well-known secret shape, with `suppressOriginalPrompt`). A locked passphrase vault means no redaction (fail open with `vault locked` warning, documented as R15).
- L8. Protocol verified by the parent against https://code.claude.com/docs/en/hooks.md (2026-11-04): `updatedToolOutput` replaces what Claude sees and must match the tool's output shape; `suppressOriginalPrompt` exists and only changes the block message (the prompt can still land in the local transcript and history, so a blocking hook does not keep a secret off disk); Bash and PowerShell are separate tools (P4 must use the matcher `Bash|PowerShell`). Not verified on a live host: the Read tool's output shape (the hook re-emits whatever structure it got).
