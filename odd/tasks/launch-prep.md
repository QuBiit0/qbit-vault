Cause: local Go is 1.27.3, CI installs Go 1.26 (go.mod `go 1.26.0`). For invalid UTF-8 bytes Go 1.26 encoding/json writes the escape `\ufffd`, Go 1.27 the literal U+FFFD; the redactor modeled only 1.27, so a value mixing literal non-ASCII text with an invalid byte, JSON-encoded by Go 1.26, survived redaction (the bytes around the invalid one would reach the agent). RED: TestJSONFormsOfInvalidUTF8AreReplaced failed on the Go 1.26 form. Fix: values with invalid UTF-8 also register the escaped variant (internal/redact/redact.go, encode.go jsonEscapeInvalid); TestJSONEscapeMatchesEncodingJSON accepts either real form. The host tests check Windows path escaping and now skip off Windows (on POSIX a `C:\` path is correctly refused as not absolute). - L5. macOS CI. The first two runs never got a GitHub-hosted macOS runner ("The job was not acquired by Runner of type hosted"; GitHub reported macOS arm64 capacity constraints): no step ran. On the next run macOS ran for the first time and failed: `runtime: kevent on fd 3 failed with 9`, `fatal error: runtime: netpoll failed` in internal/cli. Cause: TestPromptValueNeedsFD3 wrapped fd 3 in an *os.File to see whether it was open; on macOS an unused fd 3 is the Go runtime's kqueue, and the file's finalizer closed it, killing the test binary later. The same flaw was in production: openValueFD (internal/cli/promptcmd.go) wrapped fd 3 and accepted it after a Stat, so with nothing passed on fd 3 `prompt --value` would have treated the runtime's poller (kqueue on macOS, possibly epoll on Linux) as the host's channel, tried to write the value there and closed it on exit, crashing instead of refusing. RED: TestOpenValueFDRefusesAPollerAndLeavesItOpen (internal/cli/valuefd_unix_test.go) failed on Linux with the old logic (`openValueFDNum(poller) = &{...}, <nil>`). Fix: valueFDKindOK (valuefd_unix.go, fstat without wrapping) accepts only a pipe, socket, regular file or character device; openValueFDNum checks it before any *os.File exists; Windows keeps refusing --value. The fd-3 test no longer wraps fd 3. GREEN: the prompt and value-fd tests on Linux (Docker, Go 1.26.10) and Windows; macOS is checked by CI. docs/CLI.md states which descriptors are accepted.
